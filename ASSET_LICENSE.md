# Source code and visual asset licensing

> Language: [简体中文](ASSET_LICENSE.zh-CN.md) | **English**. This English text is authoritative.

MaplesAdventure uses **split licensing**. The repository's source code is open under MIT, while
visual and artistic assets are separately protected. A file-specific license or notice always
takes precedence for that file.

## Source code — MIT

Unless a file explicitly states otherwise, original MaplesAdventure source code is licensed under
the [MIT License](LICENSE), copyright (c) 2026 Axira.

This includes the project's original Java source, build logic, public API examples, and original
data/configuration logic where those files are not themselves protected artistic works. The MIT
license permits use, copying, modification, redistribution, sublicensing, forking, and reuse of
that MIT-licensed code in independent projects, subject to the MIT notice requirements.

The presence of the root MIT license **does not place MaplesAdventure visual or artistic assets
under MIT**.

## Visual and artistic assets — All Rights Reserved

Unless a specific asset carries a separate license that expressly permits additional reuse,
project-owned visual and artistic assets distributed with MaplesAdventure are **All Rights
Reserved**.

Protected visual/artistic assets include, without limitation:

- 3D models, Blockbench model files, geometry, and model data;
- textures for items, blocks, entities, equipment, particles, and interfaces;
- animations and animation assets;
- icons, GUI artwork, HUD artwork, and other graphical interface elements;
- visual-effect artwork and image resources;
- concept art, renders, illustrations, and other original visual material.

This protection applies whether an asset was created directly for MaplesAdventure, commissioned
for the project, or contributed under terms that allow MaplesAdventure to distribute it under
these restrictions. Ownership of an individual contributed or commissioned work remains governed
by the actual agreement with its creator.

## Normal use and redistribution of MaplesAdventure

You may download, install, run, and use MaplesAdventure normally.

You may also redistribute the **complete official MaplesAdventure mod/package**, including in
modpacks and server packs, provided that:

- the package and its copyright/license notices remain intact;
- protected visual assets are not extracted and redistributed as a separate asset collection;
- the redistribution does not claim authorship or ownership of MaplesAdventure's protected art;
- the protected assets are not relicensed under MIT or another license.

Copying protected assets as technically necessary to clone, build, test, or contribute to
MaplesAdventure itself does not grant permission to reuse those assets in another project.

## Independent forks, mods, resource packs, and other projects

The MIT-licensed source code may be copied, modified, forked, and used to create an independent
mod.

However, **no license is granted to reuse MaplesAdventure's protected visual/artistic assets in
an independent project**.

Without explicit written permission from the applicable rights holder, you may not:

- extract MaplesAdventure models, textures, animations, icons, GUI art, or other protected visual
  assets for use in another mod;
- copy protected assets into an independent mod, resource pack, game, website, asset pack, or
  other project;
- modify, adapt, recolor, remodel, or create derivative versions of protected assets for use
  outside MaplesAdventure;
- use protected assets as source material, templates, or development bases for an independent
  mod or other independent project;
- redistribute protected assets separately as a model pack, texture pack, UI pack, animation
  pack, or similar collection;
- claim that protected assets are covered by the repository's MIT source-code license.

A separately distributed fork or independent mod based on MaplesAdventure code must provide its
own replacement visual assets unless it has separate written permission to use the protected
MaplesAdventure assets.

Reuse outside the permissions granted here is unlicensed and may constitute copyright
infringement under applicable law.

## Separate permission

A protected MaplesAdventure visual/artistic asset may be reused outside MaplesAdventure only when:

- the asset itself explicitly carries a separate license permitting that use; or
- the applicable rights holder provides explicit written permission for the intended use.

When no separate permission or license is present, assume that extraction or reuse of the
protected visual/artistic asset in an independent project is **not permitted**.
