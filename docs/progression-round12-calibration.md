## 平衡结论与边界

- 基础 D10 对 AR4/7/10 额外减伤 20%/12.5%/9.09%，维持建议 starter 区间。
- D50 对 AR4 为55.56%，对AR30为14.29%。高防御压制低压力攻击是该曲线的结果；并非所有中高 Build 都落在20–35%。
- Generic 2点攻击对D50额外减伤71.43%，属于高防御对很小Pre输入的明显优势。没有把这一结果隐藏为“无额外问题”。
- 既有 Bow/Crossbow 的基准AR=1而非实际箭伤。对D10的额外减伤达到50%，对高Build更高。这是已有AR归一化与Pressure组合的平衡缺口；本轮没有擅自改Projectile AR或敌人参数。
- 统一大幅降低pressure可以缓解弓弩/小伤害，却会使普通近战starter额外防御远低于10–20%。因此本轮保留明确指定的默认0.10，将弓弩压力基准留作单独校准，不宣称所有武器已达理想PvP平衡。
- 以上数值不包含Vanilla Armor、Requirement或Frost；实际结算仍按独立层顺序执行。
