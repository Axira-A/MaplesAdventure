# 制作人优先编辑器

> Language: [English](editor-maker.md) | **简体中文**

实验性编辑器制作现有场景和真实的当／如果／那么规则，不新增脚本语言、节点图、任务、Prefab 或玩法回滚。

## 第一个场景

OP ≥2 或单人世界真正的主人按可重绑定 F8。创建场景默认只填名称，由服务器生成稳定 ID。
添加 → 触发区域，编辑宽高长，再添加规则：**当**玩家进入，**如果**条件满足，**那么**显示消息。
应用草稿后点击试玩。

移动不依赖右键且无惯性；右键仅用于观察。文本框和内部浮层捕获移动输入。
“更多 → 高级信息”仅是客户端显示偏好，不增加权限。普通显示隐藏 UUID、revision 和完整类型 ID。
触发区域优先展示尺寸和规则，位置／组织可折叠。点击诊断定位对象。
“自动保存 ✓”表示服务器已接受并进入世界正常保存流程，不代表立即强制写盘。

## 草稿与共享撤销

Ctrl+Z、Ctrl+Y（或 Ctrl+Shift+Z）优先撤销／重做本地草稿。同一字段 500ms 内连续输入合并，
结构编辑独立。整次应用是服务器一步原子历史。切换对象／场景、退出或试玩遇到草稿时，
提供应用并继续／放弃并继续／取消。提交失败不执行后续导航。冲突停止拖拽、清理失效草稿，不自动合并。

本地历史耗尽且无草稿时，才请求共享场景历史。所有作者看到相同的下一步及操作者，名称在作者离线后仍保留。
所以撤销也可能撤销另一位作者的修改，按钮提示说明下一步内容。恢复对象保留 UUID，
但场景和受影响对象／分组 revision 继续递增，旧请求不能重新有效；新编辑清空 redo。

每场景最多 50 步、64 MiB，全服务器 128 MiB，超预算淘汰最旧历史。仅保存受影响对象／分组、
目录及场景元数据差量，不复制整份场景。历史只在内存，重启清空；玩法标记值、物品等结果从不撤销。

## 剧情标记

选择器合并命名目录和已引用 ID。输入可读名称（支持中英文 Unicode），服务器生成
maplesadventure:flags/<uuid>。重命名不改 ID，旧无名称标记显示 path。
新建界面标记条件／动作默认**该玩家**，**整个世界**需明确选择；已有 WORLD／PLAYER 范围保持原样。
目录不初始化或清除玩法实际值。

Scene v2 添加目录（最多 1024 项，名称最多 128 字符），v1 迁移为空目录。
SavedData ID 仍为 maplesadventure_authoring；未来版本／损坏数据保留原文、只读。

## 试玩与 F8 返回

试玩使用真实 LogicRuntime，不回滚玩法结果。服务器先恢复原模式／位置，再发送关闭确认。
第三方拒绝恢复时保留恢复记录并报告失败。原玩法模式是旁观时无法进行区域触发试玩。

F8 返回先记录新的玩法返回点，再恢复服务器可信的最后编辑机位；维度、场景、边界和已加载 Chunk 必须有效。
无效时留在当前位置，不强制加载。选择／工具／滚动来自客户端界面上下文，已删除选择安全清空。
死亡、离线、换维度和撤权清除上下文。不接受客户端任意传送坐标。

## Addon 展示扩展（实验性）

现有 Descriptor 构造契约及玩法 API v1 不变。客户端 setup 可在冻结前调用
MaplesEditorClientApi.registerPresentation(Target, id, EditorPresentation)，提供分类／说明键、
可选图标资源 ID、高级显示标记和自然句式键。句式以 {field} 替换，仅用于显示。
分类／说明／句式用于 Schema 选择器和规则；图标 ID 供客户端展示 Provider 使用，
不自动下载或加入 Atlas。Common 不持有客户端渲染器。旧 Addon 无元数据仍使用服务器 Schema 表单。
重复／晚注册拒绝。见编译检查的[示例](integration/examples/EditorGizmoExample.java)。

## 协议与验证

协议 30 仅扩展 Editor 的目录／历史／试玩意图，其他玩法格式不变。撤销只发送 nonce 和预期 revision，
不上传恢复内容；目录操作只表达名称或稳定 ID，不写玩法值。现有权限、维度、只读、边界、限流、大小、
Schema 和原子提交检查继续生效。快照分页，增量断层重同步，普通玩家不接收作者数据。

运行 gradlew.bat clean test、gradlew.bat clean build。隔离 opt-in fixture 执行
/ma editorregression、/ma logicregression，保存重启后执行 persisted 分支。
合成参与者验证真实服务器分发／恢复，不能冒充双客户端视觉测试。人工验收：
Hello World、每位玩家首次访问、双 OP 共享撤销、中英／GUI 缩放、机位返回和退出后普通输入。
